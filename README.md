# Turf Clone (MVP)

En förenklad version av det location-based spelet Turf.

## Struktur
- `frontend/` – React + Leaflet (karta + GPS)
- `backend/` – Node.js + Express + PostgreSQL/PostGIS
- `docs/` – Dokumentation och anteckningar

## Kom igång
1. Klona repot
2. Sätt upp backend (se `backend/README.md`)
3. Sätt upp frontend (se `frontend/README.md`)

# Frontend
